# Roadmap

The first release focuses on dependable single-owner research. These are ideas,
not delivery promises; discuss scope in an issue before large implementations.

- Better evidence for format classification and small-channel discovery coverage.
- Flexible comparison of channel/video growth windows.
- Resuming interrupted operations with checkpoints.
- Additional UI languages and verified container architectures.
- Multi-user support only after complete authorization and ownership isolation.

Runtime LLM integration, video generation and automatic publishing are outside the
current scope. Transparent observations and understandable workflows come first.
